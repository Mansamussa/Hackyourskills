# HYS Website Development Agent Rules
Before changing design, layout, frontend behavior, images, or client-facing copy, follow the HYS Web Development Brain v4 design quality gate.
Read and apply the shared policy at https://github.com/Mansamussa/Hackyourskills/blob/main/docs/HYS_WEB_DEVELOPMENT_BRAIN_v4_DESIGN_QUALITY_GATE.md
If the shared file is unavailable, implement these safeguards: reference-and-brief analysis, explicit art direction, responsive 360/390/430/768/1024/1440 verification, Apple-inspired fluid yet restrained interaction, no diagonal arrows, preservation of prior client design feedback, and screenshot-backed QA before claiming a premium first pass. Hard failures block delivery.
For an existing project, audit first; do not silently redesign or deploy.
